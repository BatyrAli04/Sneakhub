# SNEAKHUB — интернет-магазин кроссовок (MVP)

Демонстрационный интернет-магазин кроссовок для рынка Казахстана: каталог, поиск, фильтры, карточка товара, корзина и оформление заказа с тестовой оплатой.

> ⚠️ **Демо-версия.** Цены, остатки, даты поступления и описания вымышлены. Настоящая оплата не подключена, заказы сохраняются только в браузере (LocalStorage). Изображения — векторные заглушки, а не фото реальных товаров.

## Стек

React 19 · TypeScript · Vite · Tailwind CSS 4 · React Router (HashRouter) · Lucide React. Других зависимостей и платных сервисов нет.

## Запуск локально

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # проверка типов + сборка в dist/
npm run preview   # просмотр собранной версии
```

Нужен Node.js 20+.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте в него проект (ветка `main`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт при каждом push в `main`.
4. Сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

В `vite.config.ts` задан `base: './'`, а навигация работает через `HashRouter` (адреса вида `/#/catalog`), поэтому сайт работает в любой подпапке, и прямые ссылки на страницы не дают 404.

## Что реализовано

| Раздел | Возможности |
|---|---|
| Главная | Hero со слоганом, популярные бренды, бегущая строка, хиты продаж, новые поступления, баннер Sale, преимущества, подвал с контактами |
| Каталог | 24 модели, поиск по названию/бренду/расцветке, фильтры (подборка, бренд, категория, размер EU в наличии, цена), сортировка, бейджи NEW/SALE/BESTSELLER, быстрый выбор размера из карточки, пустое состояние; фильтры хранятся в URL |
| Товар | Галерея из 4 ракурсов, описание и характеристики, размеры EU 36–46 с остатками, количество с учётом остатка, похожие модели, страница «товар не найден» |
| Корзина | Изменение количества, удаление, очистка, подсчёт суммы и скидки, прогресс до бесплатной доставки, сохранение в LocalStorage и синхронизация между вкладками |
| Оформление | Имя, телефон с маской +7, город, адрес, способ доставки (зависит от города), оплата: тестовая карта или при получении; валидация всех полей, тестовые карты успеха и отказа, проверка остатков, страница подтверждения с номером заказа |

### Тестовые карты

- `4242 4242 4242 4242` — успешная оплата
- `4000 0000 0000 0002` — отказ банка

Срок — любой будущий (например, `12/30`), CVC — любые 3 цифры.

## Структура

```
src/
  components/   Header, Footer, Layout, ProductCard, SneakerArt (заглушки фото), Badges, Logo
  context/      CartContext (корзина + LocalStorage), ToastContext (уведомления)
  data/         products.ts — демо-каталог
  lib/          format.ts, orders.ts (доставка, оплата, валидация, хранение заказов)
  pages/        Home, Catalog, ProductPage, Cart, Checkout, OrderSuccess, NotFound
```

## Как подключить реальные фото

Добавьте в товар поле `images: string[]` (файлы положите в `public/images/`) и в `ProductCard` и `ProductPage` замените `<SneakerArt … />` на `<img src={…} />`.

## Идеи для развития

Бэкенд и база товаров, личный кабинет и история заказов, настоящий платёжный шлюз (Kaspi Pay, банковский эквайринг), избранное, отзывы, таблица размеров, админ-панель.
